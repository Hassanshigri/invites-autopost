Privacy Policy

Last updated: October 29, 2026.

Invites Autopost uses TikTok Login Kit and the Content Posting API only to publish videos to the account owner's own TikTok account.

Data we access

Basic TikTok profile info (open ID, display name) and access tokens, used only to post videos you choose.

Storage

Tokens are stored as encrypted GitHub Actions secrets. We do not sell, share or use data for advertising. No data from other TikTok users is collected.

Deletion

You can revoke access anytime in TikTok settings under Security, Manage app permissions. Contact us via Fiverr to request deletion.
